# Soft Landing v0.2: the plan

Status: draft, 13 October 2026, updated after the chat tests. Two checks from you are still open (marked **Pending**). Replaces the earlier "Soft Return v0.2" plan.

**In one paragraph.** One plugin, installed from inside the Claude app with no Terminal. It works in regular chat, in Cowork and in Claude Code, on the computer and on the iOS and Android apps, and it never opens a web page. In chat, `/pause` and `/land` make Claude draw the breath right in the conversation as a small card. In the Code tab, quiet **Pause** and **Land** buttons sit above the prompt while Claude works, and the breath opens in a side panel. Where neither can draw, the same commands give a short text breath instead.

Evidence labels:
- **Tested**: I ran it. Claude Code tests use a real Claude Code with a scripted stand-in model, driven the way the desktop app drives it. Close to the app, but not the app.
- **You tested**: you tried it in your own app.
- **Docs**: from the official docs or changelog.
- **Assumed**: needs a test.

## 2. Recommendation

**One plugin, three ways to show the breath, picked by where you are. No version checks, no web pages.**

| Where you are | What `/pause` does | Mid-turn? |
|---|---|---|
| Regular chat or Cowork | Claude draws the breath as a card in its reply | See below |
| Claude Code in the app or a VS Code-based editor, 2.1.286+ | Soft Landing opens the breath in a side panel. No Claude reply needed | Yes: the Pause button |
| Older Claude Code, the terminal without drawing | Claude replies with a short text breath | No |

**How it picks, tested:**
- On 2.1.286 and 2.1.296 with the app attached, Soft Landing answered the pause command itself (then named `/soft-pause`). Zero requests went to Claude. On 16 October, typing `/pause` did the same on 2.1.302. Pressing Pause mid-turn opened the breath while Claude kept working (**Tested**).
- On 2.1.220 and 2.1.280, or with nothing drawing, the plain skill ran and Claude got the instructions for the text breath (**Tested**). That Claude then replies with exactly that text is **Assumed**.
- In this chat, Claude drew the card from the same kind of instructions and you ran the breath (**You tested**: "works great").

**Mid-turn in chat.** Regular chat has no buttons or side panels for a plugin. In this kind of long-running chat, a message you send while Claude works reaches Claude straight away. So you'd send "pause" and Claude would show the card and keep going. **Pending** your "pause" test. In a quick back-and-forth chat, you just breathe between replies.

**On your phone (iOS and Android).** The phone app is a window onto chat and onto Claude Code sessions that run elsewhere (**Docs**). So Soft Landing reaches it three ways:
- **Chat on the phone:** the same card, since plugin skills load in chat on the mobile apps (**Docs**). Whether the card animates on a phone is **Pending** your phone try.
- **A Claude Code session on your Mac, driven from the phone (Remote Control):** Soft Landing runs on the Mac and the phone draws its buttons and panel. When I connected as the phone app, the Pause and Land buttons appeared, and pressing Pause mid-turn opened the breath while Claude kept working (**Tested** on 2.1.286 and 2.1.296). The public docs still say plugin drawing shows only on the computer, so the real phone app is **Assumed** until you try it. The phone app has no text fields for plugins yet, so no Land note there.
- **Cloud sessions started from the phone:** account plugins load there (**Docs**), but nothing is drawn, so you get the text breath between turns (**Assumed**).

"Claude needs you" on the phone is already handled: the app sends a push when a Remote Control session needs a decision (**Docs**). Soft Landing doesn't add another.

**What chat costs.** Each breath in chat is one short Claude reply, so it uses a little of your plan. Claude sees the command, but never anything you type into the card. The Code side panel needs no Claude reply at all.

**Rejected:**
- **Opening a web page.** You said it breaks the flow. Dropped everywhere, including the old-version fallback.
- **A Mac menu bar app.** Installs outside Claude, needs code signing to avoid the "can't be opened" warning, and still needs a plugin to know what Claude is doing.
- **An interactive card from a connector (MCP App).** Needs a server we'd host, or a desktop-only download. And Claude has to call it, so it can't start mid-answer either.
- **Catching the typed command in Claude Code before it queues.** Doesn't fire for commands in app-style sessions (**Tested**). The button is the mid-turn path there.

## 3. Compatibility

| What Soft Landing needs | Regular chat, Cowork | Code tab, 2.1.286+ | Phone app | Older Claude Code (2.1.220+) |
|---|---|---|---|---|
| Install with no Terminal | Customize (**Docs**) | Same install. **Pending** | Follows your account. Install once on the computer or web (**Assumed**) | Same install |
| Show the breath | Card in Claude's reply (**You tested**) | Side panel (**Tested**) | Chat: card. Remote Control: panel. Cloud: text (**Assumed**) | Text breath (**Tested**, reply **Assumed**) |
| Start mid-turn | Send "pause" while Claude works (**Pending**) | Pause button (**Tested**) | Remote Control: Pause button (**Tested** as the phone app) | No |
| Know when Claude needs you | No | Yes (**Tested** on 2.1.296) | The app's own push (**Docs**) | No |
| Keep a Land note | **Pending** your grey line | Plugin's local store | No: no text fields yet | No note. Text breath only |
| Your words never reach Claude | Holds: the card keeps what you type | Holds: zero requests (**Tested**) | Holds | Holds: only the command |

**Minimum versions.** Full Code experience: Claude Code **2.1.286** (30 September 2026). The app updates its copy on launch, so anyone who opened the app since then has it. Floor: **2.1.220** (24 July 2026, about 12 weeks), where the text breath works (**Tested**). Someone who hasn't restarted in weeks gets the text breath, plus one line: "Quit and reopen the Claude app to see Soft Landing in a side panel."

Build notes from the tests:
- On 2.1.220, a `hooks.json` with only `modules` fails to load its hooks, so we keep a real `hooks` entry beside it.
- The Code layer must check that something is drawing before it answers a command. Otherwise, on 2.1.284 with early access on, the breath would open where nobody can see it.
- The card's code lives inside the skill. Skills replace text like `$1` and run anything written as an exclamation mark followed by a backtick, so the card's code must avoid both. Checked for this build.

## 4. What's in v0.2, and what moves to later

**In v0.2:**
- `/soft-landing:pause`, `/soft-landing:land`, `/soft-landing:about` (what it is, your data). Typing `/pause` or `/land` also works, unless another plugin has the same name.
- **Chat and Cowork:** the breath card. Pause: 30 seconds, dotted circle, Begin and Leave when ready, reduced motion. Land: 2 minutes in three phases, ending with "Notice the room around you." Text breath where Claude can't draw.
- **Code tab:** Pause and Land buttons while Claude works, the side panel, "Claude is asking you something" in Pause only, a one-time first-breath button, notes kept locally.
- **Older Claude Code:** the text breath and its one-line tip.
- **Distribution:** a public GitHub marketplace now, directory submission in parallel.

**Later, and what you lose:**
- **A smoother animation in chat.** The card is simple on purpose. It takes a few seconds to appear, and it can improve as Claude's own chat changes.
- **Hiding Claude's output while it works.** The Code panel sits beside the transcript, so it keeps scrolling.
- **"Claude needs you" in chat.** Chat gives a plugin no way to know.
- **"How did the last pause fit?", goals, stats, research feedback.**
- **"The commute you lost"** for the website, not the product.

**One brief change to approve:** the original brief says no model calls. In chat, each breath is a short Claude reply. That's the price of staying inside chat. The Code tab keeps the no-model-call rule.

## 5. Riskiest assumptions, and the quickest tests

1. **"A plugin added from Customize reaches the Code tab, and its buttons work there."** Test: Check B, three minutes. **Pending.**
2. **"In a regular chat, Claude draws the exact card every time, and doesn't improvise."** Test: install the plugin, then type `/pause` in five fresh chats, including once on your phone. If Claude rewrites the card even once, we shorten the card and tighten the instructions.
3. **"Sending 'pause' mid-task gives a breath without derailing Claude."** Test: your "pause" try in this chat. **Pending.**
4. **"The phone app draws Soft Landing's buttons in a Remote Control session."** Test: after Check B, turn on Remote Control for that Code session, open it on your phone, ask for something long, and look for Pause. Two minutes. If it doesn't show, phones get the card in chat and the text breath in Code.

If test 1 fails, Claude Code falls back to the text breath and chat carries the experience. I'd check with you before building further.

## 6. Testing with one non-technical person

**Before them:** run the version set (2.1.220, 2.1.280, 2.1.286, current) in the app-style harness, then you run Check B and tests 2 to 4 in your real app and on your phone.

**Who:** someone who uses the Claude app on a Mac, has a paid plan, and has never opened Terminal.

**How:** a video call, their screen shared. Send one message with the install line. Say nothing unless they're stuck for 60 seconds. Time it, count clicks.

**Their tasks, one at a time:**
1. Install Soft Landing from the message I sent.
2. In a chat, take a breath.
3. Ask Claude for something that takes a minute. Take a breath while it works.
4. Pretend you're done for the day. Use Soft Landing to leave.
5. On your phone, open a chat and take a breath.
6. Remove Soft Landing.

Run it with one iPhone user and, if we can find one, one Android user.

**Done when:** install takes under 3 minutes with at most one paste. They never open Terminal and never land on a web page. They find the breath without being told where it is. Remove takes the same place as install. Nothing needed explaining.

**Three questions after:** What did you expect when you typed the command? Was anything confusing? Would you use it tomorrow?

## Notes

**Name.** An App Store app called "Soft Landing for Hard Days" (Health & Fitness) already exists. Ours is a different thing: it doesn't assume a hard day. It's for any day, a way to step back into life after working with Claude. No trademark or domain check was done. The commands were `/soft-land` and `/soft-landing`, one word apart. On 16 October they became `/soft-landing:land` and `/soft-landing:about`.

**"The commute you lost."** Jachimowicz, Cunningham, Staats, Gino and Menges (2021), *Organization Science* 32(1): 64-85. Three field studies, 1,736 people. Thinking ahead about the work role during a long morning commute softened its toll for some people. It's about going to work, and it doesn't test anything like Soft Landing. Safe claim: "Research suggests the commute once helped people move between home and work roles." Co-author Francesca Gino has had other papers retracted after a Harvard misconduct finding. This one isn't among them as far as I know.
