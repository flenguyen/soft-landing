# Security

Soft Landing runs on your computer, inside Claude. If you find a way it could leak something, change what Claude does, or run anything it shouldn't, please tell me privately first, so it can be fixed before anyone else runs into it.

You can do that with the **Report a vulnerability** button on this repo's **Security** tab. Please don't open a public issue for a security problem.

I'll try to get back to you within a week, and I'll fix what's real. If you'd like credit for finding it, I'm happy to add your name.

What Soft Landing is meant to do, and what it can see, is under "Safety and privacy" in the [README](README.md).
